# Day 38 - Find the Difference

## Problem
LeetCode 389: Find the Difference

You are given two strings s and t.

String t is generated by randomly shuffling string s
and then adding one extra character.

Return the extra character that was added to t.

## Examples

Input:
s = "abcd"
t = "abcde"

Output: "e"

Input:
s = ""
t = "y"

Output: "y"

Input:
s = "a"
t = "aa"

Output: "a"

## Approach

1. Initialize result = 0.
2. Traverse every character in string s.
3. Apply XOR operation between result and the character.
4. Traverse every character in string t.
5. Apply XOR operation between result and the character.
6. All matching characters cancel out.
7. The remaining character is the extra character.
8. Convert result back to char and return it.

## Java Code

class Solution {
    public char findTheDifference(String s, String t) {

        int result = 0;

        for (char ch : s.toCharArray()) {
            result ^= ch;
        }

        for (char ch : t.toCharArray()) {
            result ^= ch;
        }

        return (char) result;
    }
}

## Complexity

Time Complexity: O(n)
Space Complexity: O(1)

## Key Learning

- String
- Character traversal
- toCharArray()
- Bitwise XOR (^)
- Type casting
- Finding an extra character

## XOR Properties

a ^ a = 0
a ^ 0 = a

Matching characters cancel each other.
The extra character remains.
